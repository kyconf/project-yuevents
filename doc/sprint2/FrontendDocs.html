Frontend Routes & Components

Home Page ("/")

  • Navbar – top navigation bar
    • "HeaderEvent.tsx" - Directs user to the general events page and displays a menu when hovering
    • "HeaderEventsDropDownMenu.tsx" - The menu that becomes visible when hovering over the HeaderEvent component, contains menu options that direct user to the related page
    • "DropDownMenuElement.tsx" - Simple component containing some text and link
  • Hero_Section – main landing section with images and call-to-action buttons
  • Featured Events – show 5 most recent events
  • Links – forward to events feed/clubs/join
  • Footer – page footer

Login Page ("/login")

  • LoginForm – email/password input and submit button
  • ForgotPasswordLink

Signup Page ("/signup")

  • SignupForm – name/email/password inputs
  • TermsCheckbox – accept terms & privacy

Events Calendar ("/events/calendar")

  • Component "HeaderEvents.tsx", which is a part of the website header, contains a menu that directs to this page
  • "Calendar.tsx" The container for the date selection and actual calendar
    • "DateSelection.tsx" - A search bar.
      • "SelectMonth.tsx" - Button with dropdown menu for selecting month
      • "SelectYear.tsx" - Button with dropdown menu for selecting year
    • "CalendarGrid.tsx" - Grid containing calendar cells, formatted to match the month/year
      • "CalendarCell.tsx" - Calendar cell containing eventlines
        • "EventLine.tsx" - A text box containing the titlt eof the event, hover over the box to display a corresponding hover card
          • "HoverCard.tsx" - Hover card that appears when hovering over an event line in a calendar cell
  • "SidePanel.tsx" - The side panel containing the display cards for the events held on the date selected
    • "SideCard.tsx" - An event card to be displayed in the side panel

Events Feed ("/events/event-feed")

  • Component "HeaderEvents.tsx", which is a part of the website header, contains a menu that directs to this page
  • Filter component Contain a search bar, and filtering menus
    • "InputSearch.tsx" - A search bar.
    • "MenuUpcoming.tsx" - Filter menu for upcoming vs past events
    • "MenuOrganization.tsx" - Filter menu for filtering by organizations
    • "MenuOrgType.tsx" - Filter menu for filtering by organization types, such as hobby and religious clubs
    • "MenuEventType.tsx" - Filter menu for filtering by event types
    • "MenuEventTags.tsx" - Filter menu for filtering by event tags
    • "MenuLocation.tsx" - Filter menu for filtering by where an event is taking place
    • "ResetQueryButton.tsx" - A button that clears the above filter options
    • "MenuTemplate.tsx" - This the component that provides the menu template for the above components
    • "CheckBoxMenu.tsx" - This component is the template for filter checkbox menus
    • "SingleChoice.tsx" - This component is the template for filter single choice menus
  • "EventList.tsx" - The component containing all the events to be scrolled through, with infinite scrolling enabling the user to scroll for as many events that can be fetched
    • "EventCardGroups.tsx" - Component that groups event cards by days
    • "EventCard.tsx" - UI display for the event information that is fetched

Post Event ("/events/post-event")

  • Component "HeaderEvents.tsx", which is a part of the website header, contains a menu that directs to this page

Events Clubs ("/club")

  • Component "HeaderEvents.tsx", which is a part of the website header, contains a menu that directs to this page
