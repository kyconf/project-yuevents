## ✅ Practices to Continue

- **Frequent informal check-ins:** Spontaneous meetings on Discord worked well for coordination.  
- **Shared documentation:** Centralizing all deliverables and diagrams in the `/doc` folder kept everything organized.  
- **Collaborative debugging sessions:** Pair programming helped resolve integration issues faster.  
- **Git branching workflow:** Using feature branches before merging to `main` prevented major conflicts.
