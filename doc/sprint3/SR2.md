## ✅ Practices to Continue

- Frequent integration checks between frontend and backend throughout the sprint.
- Stable Git workflow using feature branches and PRs.
- Consistent communication through Discord for quick problem-solving.
- Centralized documentation in the `/doc` directory.

---

## 🆕 New Practices to Try in Sprint 3
 
- Introduce lightweight end-to-end testing for login, event posting, and event viewing.  
- Schedule a short “integration window” before sprint end to catch breaking changes early.

---

## ⚠️ Practices to Stop or Adjust

- Avoid large, ambiguous tasks (e.g., scraper implementation) without clear architectural planning.  
- Prevent backend/frontend mismatched expectations by aligning APIs earlier.  
- Reduce overlapping ownership of multi-step features by assigning a single primary owner.
