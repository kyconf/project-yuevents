# Product Backlog

| Feature Name                  | Feature Description | Impact | Confidence | Effort |
| ----------------------------- | ----------------- | ------ | ---------- | ------ |
| Event Feed                     | As a student, I want a single, scrollable event feed that lists all upcoming university and club events so that I can easily find and stay updated on campus activities in one place. | 8  | 9  | 2 |
| Search Events (Direct Matches) | As a student, I want a search bar to find my exact hobbies/clubs right away instead of scrolling manually. | 8  | 7  | 1 |
| Event Categories and Tags      | As a student or club executive, I want events tagged by type (sports, arts, academics) so I can filter and search efficiently. | 6  | 8  | 3 |
| Post Event (Aggregator)        | As some scraper, I want to be able to send the information I have scraped to be posted on the application. | 9  | 10 | 5 |
| Post Event (Manual User)       | As a club executive, I want to be able to directly post an event to the website so that I don’t have to make an Instagram account or Discord server. | 7  | 7  | 2 |
| Event Details Page             | As a student, I want to click on an event to open a detailed page so that I can view full information such as description, time, location, and organizer before deciding to attend. | 10 | 10 | 1 |
| Events Calendar View           | As a student, I want to view events on a calendar so that I can easily see what is happening on specific days and plan my schedule accordingly. | 10 | 10 | 5 |
| Add Events to Personal Calendar | As a student, I want to add events to my personal calendar so that I can receive reminders and avoid missing activities I plan to attend. | 3  | 6  | 3 |
| Event Editing                  | As a club executive, I want to edit my posted events so that I can correct mistakes or remove events that are canceled or rescheduled. | 9  | 9  | 2 |
| Event Deletion                 | As a club executive, I want to delete my posted event for whatever reason instead of editing. | 3  | 8  | 1 |
| Web Scraper (Discord)          | As a Dev, I want to auto scrape through clubs using Discord that have accepted our services, automatically populating the DB using a bot. | 8  | 10 | 7-8 |
| Web Scraper (Instagram)        | As a Dev, I want to auto scrape through club profiles on Instagram that have accepted our services, automatically populating the DB. | 9  | 10 | 7-9 |
| Web Scraper (YUConnect)        | As a club owner, I want to automatically import clubs registered on YUConnect instead of manually filling out forms. | 2  | 7  | 5 |
| Events Duplication Detection   | As a Dev, I don’t want to manually ensure no new events were added that are already existing. | 2  | 8  | 8-9 |
| Exec/Admin Login System        | As an Exec, I want to securely log in to the platform using my login info so that I can access features and permissions appropriate to my role. | 8  | 8  | 4 |
| Loading and Empty States       | As a user, I want the app to show when content is loading or empty so I understand what’s happening. | 3  | 8  | 1 |
| Reviews/Comments               | As a student, I want to see engagement within the club or activity before I decide to commit to attending. | 1  | 6  | 3 |
| Attendance Tracking            | As a student, I want to RSVP to events so I can indicate interest and get updates if things change. | 2  | 8  | 2 |
| Admin Moderation Tools         | As an admin, I want to approve, reject, or flag events so the platform stays accurate and safe. | 3  | 8  | 4 |
| Club Profiles                  | As a student, I want club pages with descriptions, events, and executive names linked to their profiles so I can learn about the club and contact its leaders. | 6  | 9  | 3 |
| Account Creation System (Student) | As a student, I want to be able to create my own profile and organize my clubs so I can stay organized with my events for the year. | 1  | 7  | 1 |
| Account Creation System (Exec/Admin) | As an Exec, I want a club account that can be shared between my team for all club responsibilities. | 9  | 9  | 4 |
| JWT System                     | As a student, I want my session stored and also want my account to be secure as I browse YUEvents. | 5  | 5  | 4 |
| Event Analytics                | As a club executive, I want stats on RSVPs and attendance so I can evaluate engagement and plan better events. | 2  | 8  | 2 |
| Past Events/Recap              | As a student, I want to be able to see the most recent past events in a pagination so that I can read through everything. This will follow the same format as the upcoming events feed. | 2  | 8  | 1 |
